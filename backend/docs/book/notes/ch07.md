## Concepts
- **Draft 1 — unconstrained prompt** (lines 21–59): grounded opening sentence, then the model extends into unverified training-data detail (muslin-cloth storage, zari tarnishing advice not in the retrieved chunk). Named "Confident Drift in its most dangerous form" because it's subtle, not an obvious fabrication.
- **Draft 2 — over-constrained prompt** (lines 85–118): "answers must come ONLY from this information... do not guess/estimate/infer" eliminates drift but produces verbatim chunk regurgitation with no natural voice — "a model that cannot speak is not a voice. It is a display." Named a Grounding Failure of the opposite shape (uselessness).
- **Draft 3 — final** (lines 120–191, `SHOPBOT_SYSTEM`): three positive/negative instruction classes — (a) answer directly & warmly when context has the answer; (b) exact fallback sentence when it does not, with the *reason* for honesty stated in the prompt itself; (c) never use general fashion knowledge to fill gaps. This exact system-prompt text is **BOOK-SPECIFIED** and should be reproduced faithfully (REQ-F acceptance criterion: exact fallback string match).
- **C-016 Temperature = 0 justification** (lines 195–207): not a style preference — removes the non-zero probability that sampling randomness injects an unverified detail into an otherwise-correct answer. **MUST be enforced as a hard-coded config, not a tunable the operator can casually change** (threat-model item).
- **C-017 `format_docs` chunk labeling** (lines 224–260): tags each retrieved chunk with its `chunk_type` (`[Item 1 — care]`) before insertion into context — "small addition, measurable improvement in answer coherence," especially for multi-product retrieval.
- **Prompt-as-policy discipline** (lines 329–345): version the prompt text with a changelog comment; every change is a "policy change" with consequences, tested before being adopted. → REQ-N: prompts must be versioned, version recorded in logs (Section 9 AI requirement).
- **The "Final Lock" framing** (lines 347–353): retriever (gatekeeper) + prompt (final lock) = the complete Grounding Layer; removing either reopens drift.
